# Python 규칙

- Python 3.11 이상. `from __future__ import annotations`를 파일 상단에 둔다.
- 타입 힌트는 공개 함수와 데이터클래스에 필수. 내부 헬퍼는 선택.
- 경로는 항상 `pathlib.Path`. 문자열 연결로 경로를 만들지 않는다.
- 파일은 `encoding="utf-8-sig"`로 읽고 `encoding="utf-8"`로 쓴다.
  CSV만 예외로 `utf-8-sig`로 쓴다(Excel 한글 깨짐 방지).
- 예외는 구체적으로 잡는다. `except Exception:`은 최상위 진입점에서만 허용하고,
  거기서도 반드시 사용자에게 보이는 메시지로 변환한다.
- 함수 하나가 화면 한 페이지를 넘어가면 쪼갠다. 특히 `compare_file`은
  "값 모으기 / 그룹핑 / 판정" 이상으로 커지지 않게 유지한다.
- 주석은 무엇을 하는지가 아니라 **왜 그렇게 했는지**를 쓴다.
  `# 인덱스 대신 id로 매칭한다` (X) / `# 순서만 바뀐 배열이 전부 차이로 잡히는 걸 막는다` (O)
- 테스트는 `pytest`. 픽스처로 임시 폴더 트리를 만들고 실제 파일을 쓴다.
  파일 시스템을 모킹하지 않는다. 이 도구의 버그는 대부분 실제 파일에서 나온다.
- 린트는 `ruff check`. 커밋 전에 통과시킨다.
